# Exchange Simulator

Консольный серверный симулятор биржевой торговли на C#.

Сервер запускает общий рынок с одним инструментом и двумя автоматическими участниками.
Независимый консольный клиент получает состояние и отправляет торговые команды через HTTP.

Пока все внешние клиенты используют один тестовый счет, а состояние хранится в памяти сервера.


Проект находится в активной разработке.


## Основные возможности

- рыночные и лимитные заявки;
- стакан с ценово-временным приоритетом;
- частичное исполнение и отмена заявок;
- резервирование ресурсов под активные заявки;
- история операций и сделок;
- маркет-мейкер и шумовой торговый бот;
- ручная торговля через независимый консольный HTTP клиент;
- unit и сетевые интеграционные основных торговых сценариев.

## Запуск

Для запуска требуется .NET 10 SDK.

```bash
git clone https://github.com/akimtsevmaks/exchange-simulator.git
cd exchange-simulator
```

В первом терминале запускается сервер:

```
dotnet run --project exchange-simulator.Server
```

Во втором терминале запускается клиент (введите именно тот localhost который у вас в серверном терминале):

```bash
dotnet run --project exchange-simulator.Client -- http://localhost:5000/
```

Просто запуск рынка локально в консоли, без сервера:

```
git clone https://github.com/akimtsevmaks/exchange-simulator.git
cd exchange-simulator
dotnet run --project exchange-simulator/exchange-simulator.csproj
```

После запуска в консоли можно ввести `help`, чтобы посмотреть список доступных команд.
