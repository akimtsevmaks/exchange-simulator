# Exchange Simulator

Локальный симулятор биржевой торговли на C#.

Сейчас через консоль можно торговать одним инструментом вместе с двумя автоматическими участниками рынка.

Проект находится в активной разработке.

## Основные возможности

- рыночные и лимитные заявки;
- стакан с ценово-временным приоритетом;
- частичное исполнение и отмена заявок;
- резервирование ресурсов под активные заявки;
- история операций и сделок;
- маркет-мейкер и шумовой торговый бот;
- ручная торговля через консоль;
- автотесты основных торговых сценариев.

## Запуск

Для запуска требуется .NET 10 SDK.

```bash
git clone https://github.com/akimtsevmaks/exchange-simulator.git
cd exchange-simulator
dotnet run --project exchange-simulator/exchange-simulator.csproj
```

После запуска в консоли можно ввести `help`, чтобы посмотреть список доступных команд.
